# Segment: fresh-graduate

## Profile
- Education first: school, programme, expected or actual graduation, grade if the user wants it shown, relevant modules.
- Experience counts broadly: internships, part-time jobs, final-year project, research, competitions, student organisations, volunteering, freelance or personal projects. Record each as a role with dates.
- No CV yet → run cv-builder.
- Stories: draw STAR stories from projects, organisations and part-time work.

## Scoring
`must_have:40, education:20, stack:20, projects:10, scope:10` (no years weight).
- education: programme matches the posting's field or "any discipline".
- projects: internships, projects, organisations that show the skills asked for.
- A "1–2 years experience" requirement is a flag, not a cap, when the posting also mentions graduates.

## Sources
- Graduate programmes and internships on company careers pages and ATS boards (`graduate`, `management trainee`, `intern`, `entry level`).
- Country portals' entry-level filters; university career portals the user names (Filters `country_portals`).
- Graduate job boards found by web search for the user's country.

## Filters defaults
| Key | Value |
|---|---|
| seniority | intern, entry, junior, graduate, management trainee |
| exclude_keywords | senior, lead, principal, manager, head |
| employment_types | permanent, internship, graduate programme, contract (direct) |
| min_match | 65 |

## Writing
Lead with the programme and the one project or internship closest to the role. Be specific about what the user did in team projects. No apologising for lack of experience.

## Checks
- Graduate programme deadlines (many have fixed intake dates): note them in Next Action.
- Unpaid internships: flag, and note when local law limits them.
- Online tests and assessment centres: offer interview-prep for those formats.
