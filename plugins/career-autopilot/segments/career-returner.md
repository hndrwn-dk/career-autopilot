# Segment: career-returner

## Profile
- Roles before the break, with dates, as usual.
- `career_break`: dates and a one-line description in the user's own words (e.g. "full-time caregiving for my family"). The user decides how much to share; never add a reason they did not give. Never store health details.
- Skills kept up or gained during the break: courses, volunteering, community or school committees, running a household budget, small business, freelance work. Record only what the user confirms.
- No recent CV → run cv-builder.

## Scoring
`must_have:45, years:10, stack:20, certs:10, domain:5, flexibility:10`.
- years: count pre-break experience in full; do not penalise the gap.
- flexibility: the posting's hours, location and schedule fit Filters `hours_per_week`, `schedule` and `work_mode`.

## Sources
- "Returnship" and return-to-work programmes (search `returnship <country>`, `return to work programme <country>`).
- Roles tagged flexible, part-time, school hours, job share.
- Government back-to-work portals or schemes for the user's country found by web search.

## Filters defaults
| Key | Value |
|---|---|
| work_mode | any |
| employment_types | permanent, part-time, contract (direct), returnship |
| min_match | 70 |

## Writing
Mention the break once, briefly and confidently, in the user's words, then move to what they can do now. No apology, no long explanation.

## Checks
- Schedule fit: shifts or weekend work when the user asked for school hours → flag.
- Scam signals are common in "work from home" postings: apply scam-signals strictly.
